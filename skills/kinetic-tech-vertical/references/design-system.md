# Design system

这一版是“律所口播 + Kinetic Tech 包装”，不是把整条片做成模板文字片。
画面主体始终是律师，包装层只负责标题、结构提示、警示和品牌收尾。

## 画布与基调

- 1080×1920，30fps，SDR BT.709。
- 主色：`#050607` 近黑、`#E9ECEF` 银白、`#7DB2FF` 科技蓝、`#F5B92E` 警示金。
- 字体：`PuHuiTi`（Noto Sans SC，900 中文标题）、`Geist`、`Geist Mono`。
- 质感：金属渐变字、极细网格、颗粒、蓝光、角标、刻度；不要大面积发光。

## 标题

- 0–5 秒；5.1 秒前必须消失。
- 两行：主概念 + 反差；例：

```text
谅解书
≠ 没事
```

- `≠` 用金色，其余金属银白；字号 90px 左右。
- 标题在画面上方，底部不超过律师额头；不要压脸。
- 入场：逐字上浮 + 轻微缩放；出场：4.66–5.02 秒淡出。
- 标题下方一条 300px 金蓝渐变细线，1 秒内展开。

## 字幕

结构：

```html
<div id="subs">
  <span class="subpanel"><span id="subtext"></span></span>
</div>
```

- 位置：`left:0; right:0; bottom:560px; width:100%; text-align:center`。
- 不要用 `left:50%` + `transform` + 无宽度：可用宽度会变成一半，长句折行。
- 面板：深色玻璃、1px 蓝边、3px 蓝色左边、左上角小括角、圆角 14px。
- 字号 54px；白色；轻微蓝色光晕；不要白字黑边。
- `max-width:1000px`；单行优先，必要时两行。
- 整屏卡期间仍显示在 1290px 左右（卡片下方）；警示条和片尾期间隐藏。
- 字幕文字必须按剪口重新映射，不能整段均分。

## 人名条

- 位置：左侧，`left:40px; top:1000px`。
- `width:540px; height:auto; padding:16px 24px 14px 26px`。
- `display:flex; flex-direction:column; justify-content:center; gap:12px`。
- 姓名 40px，账号 28px；两行紧排但填满黑框。
- 不要用 `space-between` 撑出中间大空白；靠字号和 padding 填满。
- 严格两行：`律师：{姓名}` / `律师证账号：{账号}`；不换第三行，账号不补位、不截断。
- 显示：0 秒到片尾；整屏卡和片尾隐藏，前后 0.2 秒淡出/淡入。

## 整屏卡

- 2×2 四宫格：适合“四个因素/四个判断”。
- 三行清单：适合“三个核对项/三个步骤”。
- 所有卡在段落开始一起出现（错开 0.06 秒）；随后按口播逐条高亮。
- 高亮：边框 + 外发光，不改布局；未高亮的卡降到 0.7 透明度。
- 卡内：编号（mono 26–30）、标题（40px 金属）、说明（24–28px 灰）。
- 卡片区域结束后留 80–120px 再放字幕条，不要贴在一起。
- 背景加 `.ins-vig` 暗角；人物画面不加暗角。

## 警示条

- 位置：`left:80px; top:1200px; width:920px`。
- 金色左边框 + “注意”小徽章；主句 44px，副句 28px。
- 出现时隐藏字幕，避免同一句话重复两遍。
- 保留律师画面，不切整屏；这是节奏停顿点。

## 片尾

- 最后 2–3 秒；整屏暗场 + Logo + 律所名 + 业务 + “进行咨询”。
- 人物条、字幕、左上角 Logo 全部隐藏。
- 背景可用蓝/金双色微光；不要新造联系方式或二维码。

## 美颜

- **先 HDR→SDR**，再美颜。顺序错会发灰。
- 软件近似（本机可复现）：

```text
bilateral=sigmaS=5:sigmaR=0.14,unsharp=5:5:0.25,eq=brightness=0.01:contrast=1.01:saturation=1.01
```

- 轻度版：`sigmaS=4:sigmaR=0.10`；加强版：`sigmaS=5:sigmaR=0.14`。
- 不要把 `eq` 提亮开太大；SDR 正确后，0.01 足够。
- 原生剪映皮肤管理是另一条路径：磨皮37、美白42、均肤52、丰盈52、祛斑祛痘47、去法令纹47、祛黑眼圈47、清晰47；必须在剪映 UI 逐项应用并导出。软件近似不能冒充原生。

## HUD

- 左上：律所 Logo（白色衬底），不遮挡标题。
- 右上：时码 `HH:MM:SS:FF`。
- 四角：30px 细括号；左侧进度轨 + 圆点；右下 44 格刻度。
- 整屏卡和片尾保留 HUD；人物画面保持干净，不加暗角。

## 时间轴参考（49.25 秒实例）

```text
0.00–5.00    标题
12.25–20.11  四宫格（2×2）
21.90–27.41  三行清单
32.85–37.55  金色警示条（字幕隐藏）
46.40–49.25  片尾
```

其他时长按文案重新分配；不要为了凑时长删限定词、数字或结论。
