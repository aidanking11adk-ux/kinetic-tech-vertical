# QA checklist

命令成功、能解码，不等于内容通过。逐项记录实际看到的画面/测量值。

## 0. 预处理

- [ ] 源片 `color_transfer` 已查；HLG/PQ 已转 SDR BT.709。
- [ ] 输出色彩标记为 `bt709/bt709/bt709`。
- [ ] 1080×1920，30fps，旋转正确，无拉伸。
- [ ] 本次律师姓名、执业证账号、对应素材已确认。

## 1. 成片规格

```bash
ffprobe -v error -show_entries format=duration,size \
  -show_entries stream=codec_type,width,height,r_frame_rate,color_space,color_transfer,color_primaries \
  -of json final.mp4
ffprobe -v error -count_frames -select_streams v:0 \
  -show_entries stream=nb_read_frames -of csv=p=0 final.mp4
ffmpeg -v error -i final.mp4 -f null - && echo decode_ok
```

- [ ] 1080×1920 / 30fps。
- [ ] 帧数与时长一致（时长×30）。
- [ ] 完整解码无错误。
- [ ] H.264/AAC，48kHz 立体声，SDR BT.709。

## 2. 标题

- [ ] 0.5 秒标题已出现。
- [ ] 4.9 秒标题仍在（淡出中可接受）。
- [ ] 5.1 秒标题已消失。
- [ ] 标题不压脸、不压 Logo。

## 3. 字幕

- [ ] 位置在画面中下方（底边约 560px），不是贴底。
- [ ] 54px 玻璃科技条，单行优先，长句最多两行。
- [ ] 文字按剪口重新映射，语义与语音一致。
- [ ] 警示条期间字幕隐藏，不重复同一句。
- [ ] 片尾期间字幕隐藏。
- [ ] 错字已修正（判缓行/判缓刑、历史/律师等）。

## 4. 人名条

- [ ] 严格两行：`律师：{姓名}` / `律师证账号：{账号}`。
- [ ] 姓名 40px、账号 28px、行距 12px；两行填满黑框，中间无大空白。
- [ ] 账号字符串完整，不补位、不截断、不换第三行。
- [ ] 0 秒到片尾显示；整屏卡和片尾隐藏，前后 0.2 秒淡出/淡入。
- [ ] 不挡脸、不挡 Logo、不挡字幕。

## 5. 整屏卡

- [ ] 段落开头所有卡一起出现，不是逐张从空白长出来。
- [ ] 当前项按口播高亮，旧项降为 0.7。
- [ ] 卡片间距足够，不挤在一起；底部留 80–120px 给字幕。
- [ ] 暗角只在整屏卡和片尾；人物画面无暗角。

## 6. 美颜与色彩

- [ ] 与原片对比，黑位没有抬高、颜色没有发灰。
- [ ] 皮肤平滑但五官、发丝、衣服纹理还在。
- [ ] 文字、HUD、字幕、人物条不被美颜糊掉。
- [ ] 如使用软件美颜，明确记录“不是剪映原生 8 项数值”。

## 7. 音频

```bash
ffmpeg -hide_banner -i final.mp4 -af "ebur128=peak=true" -f null - 2>&1 | tail -12
```

- [ ] 响度 -14.5 ~ -14.8 LUFS。
- [ ] 真峰值 -1.3 ~ -1.6 dBFS。
- [ ] 原声保留，无二次变速；音画同步。
- [ ] 音效只在转场，不盖人声。

## 8. 交付

- [ ] MP4、SRT、封面、画面抽查、人员确认、剪辑说明齐全。
- [ ] 剪辑说明记录：剪口、包装、人物条、美颜类型、已验证项、未完成项。
- [ ] 原版/旧版未覆盖；需要保留的版本有独立文件。
- [ ] 记录 SHA-256。
