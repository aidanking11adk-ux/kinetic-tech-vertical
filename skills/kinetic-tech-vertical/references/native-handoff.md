# 剪映原生草稿与美颜交接

当前口播标准的完整交付包含可编辑剪映草稿和指定皮肤管理。Kinetic Tech 的 HTML 渲染器不提供这两项；不得把软件美颜、一个导入成片的草稿或 HTML 修改器当作原生结果。

## 依赖和范围

- 使用同事电脑上已安装、可用的剪映及其合法权益。需要无界面构建时另行部署与剪映精确版本匹配的 Jianying Headless 后端和 `yichen-jianying-edit` 或项目已有原生包装器；使用对应 doctor 检查。仅安装此仓库不会安装这些依赖。
- 原生工具不可用时也可通过剪映界面制作草稿。原生界面用宿主实际提供的 Computer Use；不要把别的软件的工具名、机器路径或历史“验收通过”直接照搬。
- 美颜、原生草稿、MP4/HTML、保存冷重开分别记录状态。条件缺失可先完成离线部分，指出缺失项，不能悄悄取消约定交付。

## 草稿

1. 使用相同的剪口、音轨、字幕时间、身份文字与动画时间表，新建独立草稿，保留旧稿。
2. 主视频、最终音轨、字幕、标题、身份条和其他后加文字保持可编辑轨道。整屏图示底图可用视频/图片，但后加卡片说明文字要单独保留；不能把全片压成一个带字视频轨道冒充可编辑草稿。
3. 人物画面在原生界面完成最后的皮肤管理，再完成导出和验收；后期文字与动画不参与磨皮。
4. 打开检查字幕、切口、Logo、动画、音量及资源引用，保存，正常关闭，再冷重开检查持久化。用户正在编辑时不抢控制，不强退；需离线登记时先保存并正常退出。
5. 打包后从交付位置打开草稿，确保素材引用有效；不能只复制 JSON 然后删除被引用资源。

## 皮肤管理

画面 → 美体 → 美颜 → 打开皮肤管理，对所有人物片段应用并核验：

| 项目 | 数值 |
| --- | ---: |
| 磨皮 | 37 |
| 美白 | 42 |
| 均肤 | 52 |
| 丰盈 | 52 |
| 祛斑祛痘 | 47 |
| 去法令纹 | 47 |
| 祛黑眼圈 | 47 |
| 清晰 | 47 |

不加“甜韩粉白”或其他滤镜。记录开关、实际数值和人物片段覆盖范围；会员控件不可用时记录阻碍，不绕过许可，不声称已经应用。

HTML 修改器使用本版人物处理后的干净底片和最终音轨。若软件处理版与原生版不同，必须为最终采用的一版重新生成修改器，不能拿旧底片配新 MP4。
