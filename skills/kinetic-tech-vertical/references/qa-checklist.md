# QA checklist

命令成功、能解码，不等于内容通过。逐项记录实际看到的画面/测量值。

## 0. 预处理

- [ ] 源片 `color_transfer` 已查；HLG/PQ 已转 SDR BT.709。
- [ ] 输出色彩标记为 `bt709/bt709/bt709`。
- [ ] 1080×1920，30fps，旋转正确，无拉伸。
- [ ] 本次律师姓名、执业证账号、对应素材已确认。
- [ ] 本次版本独立保存，原素材和用户修改稿未覆盖；无粗剪确认等待。
- [ ] 不加滤镜，不默认换背景、抠像、变速或 BGM；明确例外有本次要求。

## 1. 成片规格

```bash
ffprobe -v error -show_entries format=duration,size \
  -show_entries stream=codec_type,width,height,r_frame_rate,color_space,color_transfer,color_primaries \
  -of json final.mp4
ffprobe -v error -count_frames -select_streams v:0 \
  -show_entries stream=nb_read_frames -of csv=p=0 final.mp4
ffmpeg -v error -i final.mp4 -f null - && echo decode_ok
```

- [ ] 1080×1920 / 30fps。
- [ ] 帧数与时长一致（时长×30）。
- [ ] 完整解码无错误。
- [ ] H.264/AAC，48kHz 立体声，SDR BT.709。

## 2. 标题

- [ ] 0.5 秒标题已出现。
- [ ] 4.9 秒标题仍在（淡出中可接受）。
- [ ] 5.1 秒标题已消失。
- [ ] 标题不压脸、不压 Logo。

## 3. 字幕

- [ ] 位置在画面中下方（底边约 560px），不是贴底。
- [ ] 54px 玻璃科技条，单行优先，长句最多两行。
- [ ] 文字按剪口重新映射，语义与语音一致。
- [ ] 使用逐词时间，复听剪口前后；没有上句尾部与下句头部拼成一条、固定字数跨句或时间均分。
- [ ] 前提、否定词、数字、完整结论未因压时长被删。
- [ ] 警示条期间字幕隐藏，不重复同一句。
- [ ] 片尾期间字幕隐藏。
- [ ] 错字已修正（判缓行/判缓刑、历史/律师等）。

## 4. 人名条

- [ ] 有证律师：`律师：{姓名}` / `律师证账号：{账号}`；无证实习律师：`律师：{姓名}` / `实习律师`，不展示证号。
- [ ] 有证律师底框 540px；无证实习律师约 360px，贴着文字，不留大空白。
- [ ] 姓名 40–44px、第二行 28px、行距 12px；两行填满黑框，中间无大空白。
- [ ] 账号字符串完整，不补位、不截断、不换第三行（仅限有证律师）。
- [ ] 人物画面显示；整屏卡和片尾隐藏，前后 0.2 秒淡出/淡入。
- [ ] 不挡脸、不挡 Logo、不挡字幕。

## 5. 整屏卡

- [ ] 每条有与本条口播对应的整屏图示，不是通用内容占位；既有认可动画未被无关改动。
- [ ] 段落开头所有卡一起出现，不是逐张从空白长出来。
- [ ] 当前项按口播高亮，旧项降为 0.7。
- [ ] 卡片间距足够，不挤在一起；底部留 80–120px 给字幕。
- [ ] 暗角只在整屏卡和片尾；人物画面无暗角。

## 6. 美颜与色彩

- [ ] 与原片对比，黑位没有抬高、颜色没有发灰。
- [ ] 皮肤平滑但五官、发丝、衣服纹理还在。
- [ ] 文字、HUD、字幕、人物条不被美颜糊掉。
- [ ] 戴眼镜人物：眼袋已用逐帧眼下蒙版处理；`full` 档眼袋应基本消失，镜框/镜片清晰，脸颊无蒙版边。
- [ ] 至少抽 3 个人物帧放大眼下检查，不只看缩略图。
- [ ] 如使用软件美颜，明确记录“不是剪映原生 8 项数值”。

## 7. 音频

```bash
ffmpeg -hide_banner -i final.mp4 -af "ebur128=peak=true" -f null - 2>&1 | tail -12
```

- [ ] 响度 -14.5 ~ -14.8 LUFS。
- [ ] 真峰值 -1.3 ~ -1.6 dBFS。
- [ ] 原声保留，无二次变速；音画同步。
- [ ] 音效只在转场，不盖人声。

## 8. HTML 修改器（每版必验）

详细步骤见 [交付与 HTML 修改器](delivery-and-editor.md)，不得只检查文件存在或有导出按钮。

- [ ] 使用本版干净底片和最终音轨，所有后加文字独立可编辑，修改后无旧字残留。
- [ ] 标题、姓名/完整证号、水印文字、卡片、警示、片尾和字幕均可改文字、字号、颜色、字体。
- [ ] 字幕起止时间可改并有范围检查，语义和显隐逻辑保持正确。
- [ ] 实际修改一份测试副本并保存 HTML，关闭后重开，文字、样式、时间和媒体仍在。
- [ ] 从重开的 HTML 实际导出视频；抽帧确认修改进入画面，音轨可听，动画未丢失。
- [ ] 导出视频参数、时长、音画同步和完整解码通过；不接受静音/空文件或伪装 MP4。
- [ ] 正式交付 HTML 恢复正式文案，与最终 MP4 同版本；标明浏览器、依赖及打开方法。
- [ ] 记录浏览器版本、测试步骤、导出文件、截图及音频核验依据。

## 9. 原生草稿与皮肤管理

- [ ] 按 [原生交接](native-handoff.md) 逐项检查八个参数、开关及全部人物片段覆盖范围。
- [ ] 原生草稿保留可编辑视频、音频与后加文字轨道；不是单轨带字成片。
- [ ] 原生保存、正常关闭和冷重开检查完成；交付位置素材引用有效。
- [ ] 缺少原生依赖/UI 条件时明确未完成；没有以软件美颜或 HTML 替代原生交付。

## 10. 交付

- [ ] MP4、对应 HTML 修改器及依赖、SRT、封面、约定的原生草稿、画面抽查、人员确认、剪辑说明齐全。
- [ ] 剪辑说明记录：剪口、包装、人物条、美颜类型、已验证项、未完成项。
- [ ] 原版/旧版未覆盖；需要保留的版本有独立文件。
- [ ] 记录 SHA-256。
- [ ] `delivery-checklist.json` 按真实证据更新，未测试项不填写通过；任何约定交付未完成时 `complete` 为 false。
